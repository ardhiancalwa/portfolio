## Overview

Paja Barbershop is a production reservation backend built for a real business with focus on booking reliability and operational simplicity.

## Problem

Scope initially expanded too far due to overengineering and slowed delivery beyond the expected timeline.

## Goals

- Deliver a stable reservation flow for real users.
- Prevent double bookings through reliable scheduling logic.
- Keep deployment manageable for long-term business use.

## My Role

I implemented backend features, designed reservation logic, and handled deployment configuration.

## Tech Stack

- JavaScript
- Express.js
- MySQL

## Key Features

- Conflict-free reservation scheduling to prevent overlap.
- REST API for services, slots, and booking flows.
- Postman-documented endpoints for maintenance and QA.

## Architecture Decisions

- Applied feature-based backend modules for maintainability.
- Prioritized core reservation reliability before non-essential enhancements.

## Challenges

- Aligning engineering quality with real client priorities.
- Managing scope discipline in a first production project.

## Solutions

- Refocused delivery around core business-critical use cases.
- Standardized endpoint behavior and simplified rollout steps.

## Result

The system shipped with stable reservation behavior and practical usability for daily business operations.

## Lessons Learned

- Practical delivery and scope control are as critical as code quality.
- Production systems should prioritize user-critical flows first.
