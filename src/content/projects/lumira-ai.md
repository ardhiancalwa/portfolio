## Overview

Lumira AI is a secure AI inference backend for breast cancer classification with real-time API flow, authentication, and structured testing support.

## Problem

Before implementation, the team needed to align medical understanding from more than 40 papers while still delivering within a two-month timeline.

## Goals

- Build a secure and reliable backend foundation for AI-assisted diagnosis.
- Keep API workflows fast, validated, and easy to test.
- Ensure team collaboration through consistent documentation.

## My Role

I led backend implementation for API architecture, validation strategy, AI model integration flow, and secure data access design.

## Tech Stack

- TypeScript
- NestJS
- Supabase
- PostgreSQL
- Python
- Firebase

## Key Features

- Real-time AI classification endpoint integrated with a Python inference pipeline.
- JWT authentication and Row Level Security for protected medical-related flows.
- OpenAPI/Swagger docs for reliable testing and faster onboarding.
- Firebase chat endpoints to support doctor-patient communication.

## Architecture Decisions

- Chose NestJS for modular backend structure and maintainability.
- Used Supabase + PostgreSQL with strict schema validation for data integrity.
- Separated AI inference concerns from core business endpoints to keep boundaries clear.

## Challenges

- Balancing domain research depth with strict delivery schedule.
- Coordinating backend and AI integration under evolving requirements.

## Solutions

- Established shared research summaries to align team decisions quickly.
- Standardized API contracts and test workflows early to reduce integration friction.

## Result

The team delivered a stable backend with secure access control and a production-ready API workflow that supported real-time AI classification.

## Lessons Learned

- Domain-heavy projects need shared understanding before coding velocity can be sustained.
- Clear contracts and validation reduce risk significantly in sensitive systems.
